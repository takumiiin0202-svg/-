# 株式会社ミライブリッジ コーポレートサイト（たたき台）

架空の会社「株式会社ミライブリッジ（MIRAI BRIDGE Inc.）」のコーポレートサイトの枠組みです。
ビルドツールなしの静的HTML/CSS/JSで構成しています。

## ページ構成

| ページ | ファイル | 主なセクション |
| --- | --- | --- |
| ホーム | `index.html` | ヒーロー／3つの強み／サービス抜粋／お知らせ／CTA |
| 私たちについて | `about.html` | ミッション／バリュー／沿革／チーム／CTA |
| サービス一覧 | `services.html` | 4サービスの詳細／ご依頼の流れ／CTA |
| 会社概要 | `company.html` | 会社情報テーブル／代表者メッセージ／拠点一覧／アクセス／CTA |

## 代表者画像の差し替え

`assets/images/ceo.jpg` を同じパス・同じファイル名で上書きすれば、
コードを変更せずに差し替えられます。

- 表示枠は 1:1（正方形）・`object-fit: cover`。正方形の画像がトリミングなしで収まります
- 縦横比を変える場合は `style.css` の `.message-figure img` の `aspect-ratio` を調整
- PNGなど拡張子が異なる場合は、ファイル名を合わせるか `company.html` の
  `img` の `src` を変更してください

## 確認方法

任意の静的サーバで公開するか、HTMLファイルを直接ブラウザで開いてください。

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

## 現時点の状態と今後の作業

- 配色は緑を基調としています（アクセント `#2f6b4b`、文字色・境界線・背景もわずかに緑寄りのニュートラル）。色みを変える場合は `assets/css/style.css` の `:root` にあるCSS変数を差し替えれば全体に反映されます。
- レイアウトは未確定のため、可読性を保つ最小限の指定に留めています。
- 掲載しているテキスト・数値・住所などはすべてダミーです。
- 未実装の項目
  - お問い合わせページ／フォーム（各CTAの `href="#"` は仮リンク）
  - お知らせの個別ページ、一覧ページ
  - 会社概要ページの地図埋め込み（`.map-placeholder` を差し替え）
  - ロゴ画像、favicon、OGP画像
  - ヘッダー／フッターは各ページに直接記述しています。ページ数が増える場合は静的サイトジェネレータ等でのテンプレート化を推奨します。
